# Jetron Sport

[Открыть интерактивную главную](https://lysokon995-cmd.github.io/jetron-sport/)

Интерактивный вариант главной страницы Jetron Sport для согласования новой палитры.

Основной акцент: `#622573`. Наведение на основные и светлые кнопки: `#252824`, светлый текст. Исходная шапка и верхняя контактная полоса сохранены. Использованы цветные исходные изображения; фотография широкого баннера имеет разрешение 1920 × 711.

Сохранены исходные контроллеры слайдеров, галерей, вкладок, раскрытия отзывов, меню и первого экрана. Все изображения, шрифты, стили и библиотеки главной находятся в репозитории. Сборка и установка зависимостей для просмотра не требуются.

Каталог, конструкторы, оформление заказов и отправка заявок работают на основном сайте https://jetronsport.ru/. Эта копия предназначена для просмотра дизайна и взаимодействий; она не принимает платежи и не отправляет персональные данные. Аналитика в демо не подключена.

## Локальный просмотр

В корне репозитория выполните `python3 -m http.server 8000` и откройте http://localhost:8000/.

## Публикация

GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает лишнюю обработку файлов. Все пути к локальным ресурсам относительные, чтобы сайт работал и в подкаталоге репозитория.
